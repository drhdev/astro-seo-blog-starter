# Add Blog Post Prompt

Add a new blog post using the existing Astro content collection.

Requirements:

- Create one markdown post in `src/content/blog/`.
- Define title, description, publishedAt, category, tags, featuredImage, featuredImageAlt, draft and author.
- Use an existing category unless asked to create a new one.
- Add or reuse a local featured image from `src/assets/blog/`.
- Include a clear intro, headings, practical value, conclusion and internal links.
- Do not keyword-stuff.
- Run `npm run build`.
