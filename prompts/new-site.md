# New Site Prompt

Adapt this Astro starter for a new website.

Read first:

- AGENTS.md
- DESIGN.md
- README.md
- PRODUCTION.md
- src/data/site.ts
- src/data/categories.ts

Rules:

- Astro only
- Tailwind CSS
- no React or UI framework integrations
- keep sitemap, RSS, SEO metadata and Featured Image logic intact
- keep Docker and Coolify healthcheck logic intact

Update:

- site metadata
- homepage content
- navigation
- categories
- blog posts
- featured images
- Open Graph data
- robots.txt sitemap URL
- production checklist status

Then run:

```bash
npm run build
npm run guard:no-react
```
